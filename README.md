# Academic website framework

Simple English-language page structure. Personal content will be added later.

Planned public page: https://haibowanglab.github.io/academic/haibo-wang/

## 更新网页

在 GitHub 中编辑 `haibo-wang/index.html`。各个栏目都有注释标记，可逐步补充简介、研究方向、论文、教学和联系方式。保存提交后，启用的 GitHub Pages 会重新发布页面。

网站根目录 `index.html` 是学术网页入口。页面不依赖第三方脚本、图片或外部样式库。
