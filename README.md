# Academic website

Simple English-language academic page with journal articles and conference papers. Other profile sections will be completed later.

Public page: https://haibowanglab.github.io/academic/personal/

## 更新网页

在 GitHub 中编辑 `personal/index.html`：

- 在 `EDIT PUBLICATIONS` 注释下面编辑论文条目，按年份倒序排列。
- `Journal articles` 和 `Conference papers` 分别保存期刊论文和会议论文。
- 每条记录包含标题、作者、期刊或会议、年份、卷页和 DOI。本人姓名用 `<strong>` 标记。
- 新增或修订条目时，同时更新 `personal/publications.bib`，让引用下载与网页一致。
- 简介、研究、教学和联系方式继续在相应栏目注释下面补充。

保存提交后，GitHub Pages 会自动更新；浏览器可能短暂缓存旧页面。

网站根目录 `index.html` 是学术网页入口。页面不依赖第三方脚本、图片或外部样式库。

原路径 `haibo-wang/` 会自动跳转至 `personal/`；后续请编辑 `personal/` 目录中的网页及参考文献。
